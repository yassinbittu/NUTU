# NUTU

NUTU is a personal AI assistant for Mohammed Yassin.

Users can interact with NUTU through text chat and voice conversations to learn about Yassin's professional background, including his skills, education, experience, projects, and certifications.

## Planned Tech Stack

- React.js
- FastAPI
- Python
- LLM
- RAG
- Sentence Transformers
- Vector Database
- Speech-to-Text
- Text-to-Speech
